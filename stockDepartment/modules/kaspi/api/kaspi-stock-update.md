# POST /kaspi/api/v1/stock-update

Принимает новое значение остатка товара (или батч) и обрабатывает его:
- если дата активации уже наступила — override попадает в xlsx-прайс-лист при следующей генерации и пересобирает файл;
- если дата в будущем — запись сохраняется со статусом `PENDING`; cron активирует её, когда дата наступит.

---

## Запрос

**Method:** `POST`
**Content-Type:** `application/json`

### Одиночный объект

```json
{
  "product_guid":   "KZ_SKU_12345",
  "qty":            5,
  "note":           "Ручная корректировка",
  "effective_from": "2026-05-01"
}
```

### Батч (массив объектов)

```json
[
  { "product_guid": "KZ_SKU_12345", "qty": 5 },
  { "product_guid": "KZ_SKU_99999", "qty": 0, "effective_from": "2026-06-01" }
]
```

### Поля запроса

| Поле             | Тип     | Обязательное | Описание |
|------------------|---------|:------------:|----------|
| `product_guid`   | string  | да           | GUID товара. Максимум 128 символов. |
| `qty`            | int     | да           | Новый остаток (>= 0). Попадает в колонки PP1–PP5 прайса Kaspi. |
| `note`           | string  | нет          | Произвольный комментарий. |
| `effective_from` | string  | нет          | Дата активации в формате `Y-m-d`. По умолчанию — сегодня. |

---

## Ответы

### 200 — остаток(и) применены немедленно

```json
{ "status": "generated", "stocks": 2 }
```

### 200 — часть запланирована на будущее

```json
{
  "status": "generated",
  "stocks": 2,
  "scheduled": [
    { "product_guid": "KZ_SKU_99999", "effective_from": "2026-06-01" }
  ]
}
```

### 200 — все даты в будущем

```json
{
  "status": "scheduled",
  "stocks": 1,
  "scheduled": [
    { "product_guid": "KZ_SKU_12345", "effective_from": "2026-07-01" }
  ]
}
```

### 200 — ошибка валидации

```json
{
  "status": "validation_error",
  "errors": [
    { "index": 0, "errors": { "product_guid": ["Необходимо заполнить «GUID товара»."] } }
  ]
}
```

### 400 — пустое тело

```
Request body is required (JSON)
```

---

## Жизненный цикл записи (push_status)

| Статус    | Описание |
|-----------|----------|
| `PENDING` | Дата активации ещё не наступила. |
| `SENT`    | Override применён, остаток попадает в xlsx. |
| `ERROR`   | Ошибка при генерации Excel. |
| `SKIPPED` | Запись пропущена (вытеснена более новой). |

---

## Активация отложенных остатков (cron)

Записи со статусом `PENDING`, у которых `effective_from` уже наступил, активируются автоматически (когда будет заведён cron-экшен, аналогично ценам):

```
php yii cron/kaspi-activate-pending-stocks
```
